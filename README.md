# Dynamic Rule Engine (DDD / .NET 8)

## What is included

- Four projects: Domain, Application, Infrastructure, Framework.
- PostgreSQL + EF Core persistence for per-device rules, processed MQTT event IDs, and transactional outbox records.
- Redis active-rule cache with 60-second TTL and explicit invalidation after rule creation.
- JSON condition definitions compiled into Lua by `LuaRuleCompiler`; Lua evaluation uses MoonSharp SoftSandbox.
- MQTTnet background worker subscribes to `devices/+/telemetry`.
- RabbitMQ topic exchange `rule.actions` and an outbox publisher worker.
- Unit of Work with EF Core transaction boundaries.

## Important limitations before production

1. This starter compiles only flat `All` conditions with primitive values and comparisons. It intentionally does not accept client-provided Lua, loops, or functions. The generated script is the only script source. MoonSharp SoftSandbox is not an OS-level security boundary; if you ever execute user-authored scripts, isolate the runtime in a separate process/container with resource limits.
2. Outbox publishing is at-least-once, not exactly-once. If RabbitMQ confirms a publish and the process crashes before marking the outbox row published, the message may be sent again. Consumers must deduplicate by `messageId`.
3. The sample's event idempotency checks are backed by a primary key, but concurrent duplicate deliveries can race and one transaction may fail with a unique-key violation. Add a provider-specific conflict-safe insert/retry strategy for a fully hardened consumer.
4. The outbox worker is intentionally minimal; add row claiming/locking (e.g. `FOR UPDATE SKIP LOCKED`), exponential backoff, and a dead-letter policy before running multiple worker replicas.
5. MQTT anonymous access and local development credentials are for local-only use. Configure broker authentication/TLS, API auth, validation, limits, and observability before deployment.
6. A matched action's `RoutingKey` is controlled by the rule definition but validated against a conservative character allowlist. Further restrict allowed action types and routing keys per tenant/device in production.
7. A rule update/delete API, domain event dispatch, and a full rule history model are not included in this initial vertical slice. The schema already carries a version field.

## Run locally

Install .NET 8 SDK and Docker Desktop. The source archive was not compiled in the authoring environment because the .NET SDK was unavailable there; run `dotnet build` locally and resolve any package/API differences if your installed SDK differs. From this folder:

```powershell
docker compose up -d
dotnet tool install --global dotnet-ef
dotnet restore
dotnet build

dotnet ef migrations add InitialCreate --project Src/Infrastructure/Infrastructure.csproj --startup-project Src/Framework/Framework.csproj --output-dir Persistence/Migrations
dotnet ef database update --project Src/Infrastructure/Infrastructure.csproj --startup-project Src/Framework/Framework.csproj

dotnet run --project Src/Framework/Framework.csproj --urls http://localhost:5000
```

Swagger: http://localhost:5000/swagger
Health: http://localhost:5000/health
RabbitMQ management: http://localhost:15672 (guest/guest)

## Create a rule

```powershell
$rule = @'
{
  "name": "High temperature alert",
  "enabled": true,
  "definition": {
    "all": [
      { "field": "temperature", "operator": ">", "value": 80 }
    ],
    "actions": [
      {
        "type": "publish",
        "routingKey": "device.alert.critical",
        "payload": { "severity": "critical", "reason": "temperature-threshold" }
      }
    ]
  }
}
'@
Invoke-RestMethod -Method Post -Uri 'http://localhost:5000/api/devices/device-42/rules' -ContentType 'application/json' -Body $rule
```

## Publish MQTT telemetry

Install `mosquitto-clients`, or use any MQTT client. Publish to `devices/device-42/telemetry` with payload:

```json
{
  "eventId": "evt-000001",
  "timestamp": "2026-10-16T12:00:00Z",
  "properties": { "temperature": 85 }
}
```

The rule matches and an action message is written to PostgreSQL outbox, then published to RabbitMQ exchange `rule.actions` using routing key `device.alert.critical`. Bind a queue to that exchange/routing key to observe messages.

Example using mosquitto_pub:

```bash
mosquitto_pub -h localhost -t devices/device-42/telemetry -m '{"eventId":"evt-000001","timestamp":"2026-10-16T12:00:00Z","properties":{"temperature":85}}'
```

## Telemetry contract

Topic: `devices/{deviceId}/telemetry`

Payload fields: `eventId` (required and stable across retries), `properties` (flat object of primitive values), optional `timestamp`.

## Migration note

The migration is generated by `dotnet ef` from the configured EF Core model. It is intentionally not hand-authored in this starter so the generated migration matches the exact EF Core provider/tooling installed on your machine.

## Example of DDD layering

```cs
//------------------------------------ controller
[Authorize]
[Route("[controller]")]
public class ParameterController(
    ICustomLogger<ParameterController> logger,
    IParameterService parameterService
) : BaseController
{
    [HttpPost("form/{workspaceId:guid}/{formId:guid}")]
    [ProducesResponseType(typeof(DefaultResult<List<ParameterRes>>), StatusCodes.Status200OK)]
    public async Task<IActionResult> CreateFormParameters(
        [FromRoute] Guid workspaceId, [FromRoute] Guid formId, [FromBody] CreateFormParameterReq body)
    {
        var response = await parameterService.CreateFormParameters(workspaceId, formId, body.FormParameters);

        logger.Log(LogLevel.Information, "Create form parameter process completed", nameof(CreateFormParameters));

        return Ok(response);
    }
}
//------------------------------------ interface 
public interface IParameterService
{
    Task<List<ParameterRes>> CreateFormParameters(Guid workspaceId, Guid formId, List<CreateParameterReq> data);
}
//------------------------------------ service  
public sealed class ParameterService(
    IReportParameterService reportParameterService,
    ICustomLogger<ParameterService> logger,
    ISubFormService subFormService,
    IRoleService roleService,
    IUnitOfWork unitOfWork
) : IParameterService
{
    public async Task<List<ParameterRes>> CreateFormParameters(
        Guid workspaceId, Guid formId, List<CreateParameterReq> data)
    {
        logger.Log(LogLevel.Information, "Inserting parameters of form: {FormId}",
            nameof(CreateFormParameters), formId);

        // Validation
        var form = await unitOfWork.Form.GetById(formId) ?? throw new FormNotFoundException();
    }
}
//------------------------------------ unitOfWork interface
public interface IUnitOfWork : IBaseUnitOfWork
{
    public IFormRepository Form { get; }
}  
//------------------------------------ repository
public class FormRepository(DataEntryDbContext dbContext) : IFormRepository
{
    public async Task<Form?> GetById(Guid id)
    {
        return await dbContext.Forms
            .WithQueryName("Forms_GetById")
            .AsActive()
            .Where(f => f.Id == id)
            .Include(f => f.Settings)
            .Include(f => f.SubForms)
            .ThenInclude(sf => sf.Parameters.Where(p => p.DeletedAtDateTime == null))
            .ThenInclude(p => p.SpecialParameters.Where(sp => sp.DeletedAtDateTime == null))
            .ThenInclude(sp => sp.Items)
            .Include(f => f.Shift)
            .Include(f => f.StatusFlow)
            .ThenInclude(f => f.Statuses)
            .Include(inc => inc.Parameters.Where(fps => fps.DeletedAtDateTime == null))
            .ThenInclude(tin => tin.SpecialParameters.Where(sp => sp.DeletedAtDateTime == null))
            .ThenInclude(tin => tin.Items)
            .AsSplitQuery()
            .FirstOrDefaultAsync();
    }
}
//------------------------------------ dbContext
public class DataEntryDbContext(
    ICoreAuthorizationHandler authorizationHandler,
    DbContextOptions<DataEntryDbContext> options
) : BaseDbContext<DataEntryDbContext>(authorizationHandler, options)
{
    public DbSet<Form> Forms { get; set; }
}
//------------------------------------ domain
public class Form : AggregateRoot, ICloneable, ISearchable
{
    //...
}
```
